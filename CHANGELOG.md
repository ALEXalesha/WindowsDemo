## Unreleased

- 2026-10-26 - Published as a separate repository on GitHub, with a start page; the games open by links to their own GitHub Pages.
- 2026-09-27 - Review fixes: a game is paused when its window is minimized, closed or inactive; a folder cannot be copied or moved into itself; snapping after "Maximize" remembers the old size; write errors show "Not saved" and roll back; a second tab sees the changes; renaming keeps Recent, wallpaper, clipboard and the open Notepad in step; Notepad opens a large file read-only; the theme reaches Paint and Messenger.
- 2026-09-27 - An even Media Player icon; the hub games open as full versions in their own windows, with a "Games" folder; a minimized game is paused.
- 2026-09-26 - One strong Windows-like shell: files in IndexedDB, 11 own apps (File Explorer, Recycle Bin, Notepad, Calculator, Settings, offline Browser, Photos, Media Player, Clock, Weather, Terminal) plus Paint and Messenger, window snapping, task view, notifications.
- 2026-09-26 - Windows behave like windows (stay on screen, resize by edges and corners, maximize by double click), the taskbar shows running apps, dead buttons work or are gone, files and settings survive a reload, Calculator without eval, everything fits in 1024x700, own logo instead of the four squares.
